# 第3回 解答

## 演習

- 第1回（素のLLM）とエージェントの回答の違い：素のLLMは質問をそのままモデルに送り、モデルが持つ知識で回答する。エージェントは回答前に `search_glossary` で用語集を検索し、その結果を根拠に回答するため、講座固有の「3レベル」も用語集の `homework-levels` に沿って説明できる。回答の表現は実行ごとに異なる。
- `--trace` で見えたツール呼び出し（ツール名と引数）：`uv run python -m app.agent --trace "LoRAとQLoRAの違いは？"` の `[tool call]` 行を実行結果から転記する。`search_glossary` の引数 `query` は用語1つを指定するが、実際に呼ばれる回数や値はモデルの判断によるため、ソースだけでは確定しない。
- 1つの質問での LLM 呼び出し回数（`requests`）：上の実行結果の `[usage]` に表示される `requests` の値を記録する。ツール呼び出しを含むループの回数によって変わるため、固定値ではない。
- 追加したツールと、docstring に書いた説明：`make_quiz(lecture: int) -> str`。指定した回の用語から1つを選んで確認問題と答えを返す。「第2回の確認問題を出して」のような復習用の問題を求められたときに使う、と説明した。

## 宿題

- 取り組んだレベル：実装
- やったこと：学習内容をlearning_log/の日付別Markdownに追記するsave_learning_logを追加し、実行前に利用者の承認を求める仕組みを実装した。確認画面にはツール名と保存内容を表示し、明示的に許可した場合のみ承認するようにした。
